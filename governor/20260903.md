# 쓰기 화면 > 기점·종점 주소 관련
input에 class `fake-disabled`를 붙이고 조건에 따라 떼주시면 됩니다
```html
<input type="text" name="addressStart" aria-label="(기점)주소" class="wrtfd-ipt wrtfd-ipt-text fake-disabled" readonly="" placeholder="장소찾기를 눌러 주소를 검색하세요" required="">
```
